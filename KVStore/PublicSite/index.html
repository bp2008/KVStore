KVStore

A public, account-free, short-lived key/value store for moving small blobs of data between your own devices.

How it works

An app on one device uploads a value under a long random key, then shows you that key (for example as a QR code or a word phrase). You enter the key on another device, and the app there downloads the value. There are no accounts. Anyone who knows a key can read, overwrite, or delete its value, so keys must be long and random, and apps should encrypt values before uploading them.

Every item is deleted automatically when it expires, at most {{maxTtl}} after it was stored. Values can not be listed, searched, or downloaded by link.

For developers

Apps store and read values through a small HTTP API: every operation is a POST request to /v1/<operation>, and values can be sent as raw bytes or as base64 inside JSON. Any web page may call it, without a CORS preflight request. Read the API documentation, or try each operation from your browser with the API tester.
