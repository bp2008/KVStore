Buckets

A bucket is a named namespace with its own limits. Clients can only use buckets that exist here; the public API never creates buckets. Names are 1–32 characters from the base32 alphabet (a–z, 2–7) and are not case-sensitive.

Bucket

When a bucket reaches its item count or total bytes limit, the items closest to expiring (expired items first) are evicted to make room. Renaming a bucket moves its items to the new name.

Settings

Changes are saved to the settings file and take effect immediately.

Global defaults

Template for newly created buckets. Changing these does not alter existing buckets.

Rate limits

Per client (IPv4 address or IPv6 /64). Each client has a bucket of tokens that starts full and refills continuously.

LimiterCapacity (tokens)Refill (tokens per hour)Consumed by
Writesput, del (1 each)
Readsget, info (1 each)
Bytesput (1 per byte stored)

Applying a change replaces the rate limiters: every client's buckets are reset to full.

The Bytes capacity should be at least as large as the largest bucket's maximum item size, or items of that size can never be stored.

Key format

Strict keys carry 160 bits and make low-entropy keys like "settings" or "test" impossible. Permissive mode lets clients choose weaker keys.

Maintenance

The database is checkpointed after each expiry sweep. Expired items are never served, whether or not they have been swept.

Public API and landing page

The public API should listen on loopback and be exposed only through a Cloudflare Tunnel. The Admin Console binding () can only be changed in the settings file.

Danger Zone

Delete one item (takedown)

Items can not be listed or searched, so a takedown request must supply the exact bucket and key. This reports only whether an item was deleted.

Flush a bucket

Deletes every item in the bucket. The bucket itself remains.

Flush everything

Deletes every item in every bucket. Type DELETE to confirm.

Rebuild the database

Rewrites the metadata database file to reclaim unused space. All storage operations wait until it is finished.
